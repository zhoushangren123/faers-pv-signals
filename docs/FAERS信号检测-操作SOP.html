FAERS 不良反应信号检测 · 操作 SOP

怎么跑 · 怎么判读 · 怎么归档 — 配套《临床研发药物警戒业务说明》
归属：临床研发部 / 药物警戒 版本：v1.0（演示版） 适用：已上市品种重点监测 / 月度自检

1. 目的与范围

规范使用 FAERS 信号检测流水线（取数 → 信号检测 → 交互展示）对指定药品开展自发报告库不成比例分析， 统一「运行、判读、归档」三步动作，使初筛结果可复现、可追溯、可交接。本 SOP 仅覆盖工具操作层面； 任何安全性结论仍须由药物警戒 qualified person 在 PV QMS 框架内判定。

2. 角色与职责

角色职责
PV 操作员按本 SOP 运行工具、导出榜单、填写《信号检测记录表》、初步标注。
PV 复核人 / QP对强 / 中信号做专业判读，决定是否升级为正式信号、是否进入 PSUR/RMP 或上报。
临床研发负责人接收月度汇总，用于品种安全性定位与申报沟通决策。

3. 前置准备（一次性）

  1. 环境：本机装好 Python 3.9+，联网可访问 api.fda.gov。
  2. 安装依赖（项目根目录执行）： 
    pip install -r requirements.txt
    依赖含 streamlit / requests / pandas / matplotlib。
  3. 确认四个脚本就位：faers_openfda_ingest.py、faers_signal_detection.py、 severity_model.ipynb、streamlit_faers_app.py。

4. 怎么跑（两种入口）

方式 A — Streamlit 交互（推荐日常使用）

streamlit run streamlit_faers_app.py
  1. 浏览器打开本地地址，在「药品通用名」输入大写英文名（如 ASPIRIN）。
  2. 来源选「自动发现」（零前置数据，自动取该药报告频次最高的反应词）；或上传取数 CSV / 手动粘贴反应词。
  3. 设置时间窗（默认 2022-01-01 ~ 2026-12-31）与候选词数量，点「开始检测」。
  4. 等待进度条完成，查看 Top 信号榜（条形图 + 明细表），点「下载 CSV」。

方式 B — 命令行（批量 / 留痕）

# 从取数 CSV 自动提取候选词（推荐，结果最稳）
python faers_signal_detection.py --drug ASPIRIN --csv faers_aspirin.csv --top_terms 25

# 或显式指定反应词（快速验证）
python faers_signal_detection.py --drug ASPIRIN --reactions "Gastric haemorrhage;Headache;Nausea"

# 如需先拉取原始报告（取数层）
python faers_openfda_ingest.py --drug ASPIRIN --max 2000 --date_from 2023-01-01

输出：signals_<drug>.csv + 控制台 Top 榜。限速：匿名约 40 次/分；填 --api_key 可放宽。

5. 怎么判读

5.1 三个指标看什么

指标含义怎么看
ROR
报告比值比		该药报告某反应的比值，相对「其他药报告该反应」的倍数。 值越大越异常；95%CI 下限 > 1 才有统计意义。
PRR
比例报告比		经典「比例报告比」。 PRR ≥ 2 且 χ² ≥ 4 且 a ≥ 3 才达标。
IC
贝叶斯信息分量		BCPNN 的信息增益，对稀疏数据稳健。 IC025 > 0 视为信号（下限为正才稳）。

5.2 强度分级（自动打标）

强 · 3/3 三指标全中，关联最稳健，优先复核； 中 · 2/3 两项达标，需结合临床判断； 弱 · 1/3 仅一项，多为噪声或弱关联，一般仅记录。

5.3 判读红线（必读）

  • 关联 ≠ 因果。FAERS 是自发报告库，信号只说明「该反应被报告得异常多」，不证明是药物所致。
  • 频次高 ≠ 重要。头痛/恶心等常见非特异性反应常呈中信号，临床意义需结合说明书与医学知识。
  • 人群偏倚。数据以欧美为主，结论需结合中国人群与国内 ADR 监测数据再下判断。
  • a < 3 不判信号。样本过少时任何指标都不可靠，直接记为「数据不足」。

5.4 判读 Checklist（复核人用）

  1. □ 强信号：是否已有说明书 / 标签警示？无 → 标记「新安全信息」。
  2. □ 中信号：是否已知类别反应（如该类药共性）？是 → 降权记录。
  3. □ 是否与国内 ADR、文献、竞品数据交叉印证？一致 → 提升置信度。
  4. □ 是否影响在研 / 在市品种的安全性定位或沟通策略？是 → 升级。

6. 怎么归档

6.1 归档物

  • 原始输出：signals_<drug>.csv（完整四指标 + 强度）。
  • 可视化：Streamlit 榜单截图（含药品名、时间窗、运行日期）。
  • 复核记录：《信号检测记录表》一行（见下），含复核人签字 / 系统留痕。

6.2 命名与存放

PV/信号检测/<年份>/<YYYYMMDD>_<DRUG>_FAERS_signals.csv
PV/信号检测/<年份>/<YYYYMMDD>_<DRUG>_FAERS_记录表.xlsx

6.3 《信号检测记录表》字段

字段说明
运行日期 / 操作员谁、何时跑的
药品 / 时间窗 / 来源自动发现 or CSV or 手动
Top 信号及强度强/中/弱 + 关键指标
复核结论噪声 / 已知 / 新信息 / 升级
后续动作进入 PSUR / 上报 / 持续监测 / 关闭

7. 频率与触发

  • 月度自检：对本团队负责的重点监测品种各跑一次，更新记录表。
  • 事件触发：竞品 / 同类品种出现新强信号、说明书修订窗口、CDE 沟通前，临时加跑。
本 SOP 为操作层面规范，不构成医学结论或监管承诺；所有安全性结论须由 qualified person 在持有人药物警戒体系（PV QMS）内结合完整证据链判定。数据来源：FDA openFDA（公开、免费、免授权）。
